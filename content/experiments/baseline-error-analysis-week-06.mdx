## Purpose

This record summarises the public part of the Week 6 baseline analysis. The aim was to interpret model behaviour after the initial DSIFN-CD and WHU-CD baseline checks, not to publish final benchmark rankings.

## Analysis Structure

| Layer | What was checked |
| --- | --- |
| Region quality | Precision, Recall, F1-score, and IoU were used to organise false positives and missed changes. |
| Boundary quality | Boundary F1 and Boundary IoU were used to inspect edge alignment with a tolerance-band interpretation. |
| Dataset behaviour | DSIFN-CD and WHU-CD were kept separate when reasoning about scene content and mask convention differences. |
| Qualitative review | Prediction examples were interpreted through error categories instead of only aggregate values. |

## Error Categories

| Category | Public interpretation |
| --- | --- |
| False positives | Candidate changes can be triggered by appearance differences that are not true mask changes. |
| Missed changes | Small or low-contrast changed regions require attention beyond aggregate overlap. |
| Boundary displacement | Slight edge shifts can matter visually even when region overlap remains acceptable. |
| Domain shift | Illumination, registration, and spatial-resolution differences can change the input distribution between image pairs or datasets. |

## Output

The output of this record was a design-facing error taxonomy. Detailed numerical benchmark values remain internal until the controlled comparison stage, but the public conclusion is that later model design must preserve both region consistency and boundary quality.
