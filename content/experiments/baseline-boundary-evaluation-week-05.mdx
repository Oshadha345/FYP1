## Metric Definitions

| Metric | What it measures |
| --- | --- |
| Precision | How many predicted changed pixels are correct. |
| Recall | How many true changed pixels are recovered. |
| F1-score | Balance between precision and recall. |
| IoU | Overlap between predicted and ground-truth change masks. |
| Boundary F1 | Boundary precision/recall using a tolerance band around edges. |
| Boundary IoU | Boundary overlap quality near object edges. |

## Boundary Evaluation Detail

The boundary metrics use a 3-pixel tolerance band. This is important because exact edge alignment can be too strict when masks are rasterized, but a tolerance that is too large would hide boundary errors.

```python
def boundary_score(pred_edges, gt_edges, tolerance_px=3):
    pred_band = dilate(pred_edges, radius=tolerance_px)
    gt_band = dilate(gt_edges, radius=tolerance_px)
    precision = overlap(pred_edges, gt_band) / max(count(pred_edges), 1)
    recall = overlap(gt_edges, pred_band) / max(count(gt_edges), 1)
    return 2 * precision * recall / max(precision + recall, 1e-8)
```
