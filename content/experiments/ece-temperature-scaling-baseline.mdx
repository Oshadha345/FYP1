## Protocol

1. Train the baseline classifier.
2. Freeze weights.
3. Optimize $T$ on the validation split.
4. Report ECE, NLL, and accuracy.

```bash
python experiments/calibration/run.py --dataset cifar10 --bins 15 --temperature-scale
```

| Metric | Before | After |
| --- | ---: | ---: |
| ECE | 0.082 | 0.021 |
| NLL | 0.714 | 0.691 |
| Accuracy | 0.876 | 0.875 |

> [!WARNING]
> Reuse of the validation split for model selection and calibration can overstate the gain.
