## Learning Goal

This learning project studies one basic question:

> When a machine learning algorithm says two samples are close, what does that mean?

For the FYP, the most relevant part is not only Euclidean distance. Change detection evaluation also depends on overlap measures, boundary mismatch, and distribution shift.

## Completed Work

| Area | Status | Relevance to FYP |
| --- | --- | --- |
| Norm-based distances | Completed | Builds intuition for feature-space geometry. |
| Euclidean, Manhattan, Chebyshev, Minkowski | Completed | Helps compare how feature spaces behave under different assumptions. |
| Standardized Euclidean and weighted Minkowski | Completed | Useful when satellite image features have different scales or importance. |

## FYP Connection

| Distance family | FYP use |
| --- | --- |
| Jaccard / IoU | Main overlap measure for binary change masks. |
| Dice | Useful when changed pixels are sparse. |
| Hausdorff | Boundary-sensitive evaluation for region edges. |
| Wasserstein | Possible future tool for distribution shift and generative mask outputs. |
| Mahalanobis | Useful when feature channels are correlated. |
