## Completed Section

This week I completed the angular and correlation-based part of the `distance-geometry-ml` learning project.

| Measure | Main idea | FYP connection |
| --- | --- | --- |
| Cosine similarity | Compares vector direction. | Useful when feature magnitude is less important than representation direction. |
| Cosine distance | Converts cosine similarity into dissimilarity. | Useful for comparing learned feature maps or embeddings. |
| Pearson correlation | Measures linear relationship after mean-centering. | Useful for checking whether model features move together. |
| Spearman correlation | Measures monotonic relationship using ranks. | Useful when feature relation is not strictly linear. |

## Why This Matters

Feature-space comparisons became important during Week 05 reading and private experimentation. Angular and correlation measures help build the intuition for comparing representations without requiring identical raw activations.
