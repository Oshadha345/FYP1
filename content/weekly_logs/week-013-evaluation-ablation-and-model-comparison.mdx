## Key Observations

| Observation | Evidence |
| --- | --- |
| Backbone scaling effect | Scaling from MambaVision-T to MambaVision-B increased F1 from 94.58% to 95.77% and IoU from 89.72% to 91.89%. |
| Highest OA | MambaVision-B recorded 97.07% OA. |
| Efficiency tradeoff | MambaVision-T used 46.80M parameters and 50.05 GFLOPs while maintaining 94.58% F1. |
| Balanced choice | MambaVision-S recorded 65.40M parameters, 64.08 GFLOPs, and 95.67% F1. |

## Decision

MambaVision-S is the balanced configuration for standard deployment because it provides strong accuracy with moderate parameter and compute cost. MambaVision-B is preferred only when maximum precision is the priority.
