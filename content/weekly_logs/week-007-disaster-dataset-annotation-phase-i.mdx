## Dates

07/06/2026 - 13/06/2026

## Planned Work

- Initiation of Disaster Dataset Annotation Phase I.
- Selection and preprocessing of bi-temporal satellite images for annotations.
- Production of binary change maps and masks for selected change scenes.

## Completed Work

| Task | Output |
| --- | --- |
| Scene selection | Selected 200 representative bi-temporal remote sensing scenes containing significant land-use and infrastructure changes. |
| Manual annotation | Produced high-quality binary change masks to distinguish real changes from seasonal and illumination variation. |
| Public examples | Prepared five before/after/mask triplets for reviewer-facing evidence. |
| Quality planning | Planned annotation quality checking and verification for the next review. |

## Decisions

| Decision | Reason |
| --- | --- |
| Use annotated masks for later training and evaluation. | They provide ground truth masks for change detection models. |
| Proceed to annotation quality checking. | The first annotation phase must be verified before drawing conclusions. |
| Keep binary masks first. | The FYP benchmark and model design are centred on binary change detection. |
