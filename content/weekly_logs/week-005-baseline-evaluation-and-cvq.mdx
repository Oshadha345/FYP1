## Technical Challenge

| Challenge | Resolution direction |
| --- | --- |
| Boundary metric correctness | The custom boundary scripts must extract binary edge pixels and match predicted boundaries to ground truth within the strict 3-pixel tolerance band. |
| Hyperparameter sensitivity | Fine tuning hyperparameters was identified as important for stable model performance. |
| LoveDA class imbalance | LoveDA has a highly imbalanced class distribution, and the background class is ignored during evaluation. |
| Confidential experiment details | Architecture sketches, ablations, checkpoint details, and numeric results are kept in the private research diary only. |
