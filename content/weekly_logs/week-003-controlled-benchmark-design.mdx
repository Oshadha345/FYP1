## Findings

| Model family | Observation |
| --- | --- |
| CNNs | Lightweight and efficient for training, but limited in global context. |
| Transformers | Stronger context modeling, but attention cost can be high. |
| Hybrid models | Can combine CNN locality with Transformer or SSM context. |
| State-space models | Mamba-style encoders are promising for efficient long-range modeling. |
| Diffusion feature extraction | DDPM-CD shows that pretrained generative models can support change detection features. |

## Decisions

| Decision | Reason |
| --- | --- |
| Compare model families under a controlled protocol. | Architecture conclusions are weak if training, crop size, and dataset settings differ. |
| Separate encoder study from decoder design first. | This makes it easier to identify whether performance changes come from representation quality. |
| Include overlap and boundary metrics in the evaluation plan. | F1 and IoU do not fully explain boundary quality. |
