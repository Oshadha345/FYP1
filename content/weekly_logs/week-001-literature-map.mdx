## Findings

| Area | Observation |
| --- | --- |
| Model families | CNN and Transformer based models are the main starting points for recent remote sensing change detection. |
| Datasets | DSIFN-CD, WHU-CD, SYSU-CD, and LEVIR-CD are common benchmark datasets. |
| Open problem | Change class limitations, dataset bias, spectral noise, and domain shift can reduce model robustness. |
| Transformer direction | ChangeFormer is a useful reference for Siamese Transformer change detection [@bandara2022changeformer]. |
| Dataset direction | STANet and LEVIR-CD are useful references for attention-based change detection and benchmark dataset context [@chen2020stanet]. |
| Difference modeling | LDGuid suggests that explicitly learning semantic differences can improve robustness [@zhao2026ldguid]. |

## Decisions

| Decision | Reason |
| --- | --- |
| Use classical image inspection before model selection. | Dataset characteristics should be understood before designing a model. |
| Track dataset limitations from Week 1. | A model improvement is weak if it only works on biased or narrow benchmarks. |
| Keep the first benchmark binary and controlled. | It gives a cleaner evaluation surface before exploring semantic change detection. |
