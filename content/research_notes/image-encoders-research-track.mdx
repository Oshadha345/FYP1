## Research Goal

The purpose of this workspace is to understand how different image encoders behave before using them in change detection benchmarks.

## Tracks

| Track | Models | Reason for inclusion |
| --- | --- | --- |
| CNN | ResNet, ConvNeXt | Efficient local feature extraction and strong baselines. |
| Transformer | ViT, DeiT, Swin | Global context and attention-based reasoning. |
| SSM/VSS | MambaVision, VMamba, Spatial-Mamba | Linear-complexity global modeling and possible edge efficiency. |

## First Milestone

| Item | Target |
| --- | --- |
| Models | ResNet18 and ResNet50 |
| Dataset | ImageNet-100 |
| Crop sweep | 160, 192, 224, 256, 320 |
| Metrics | Top-1, Top-5, FLOPs, parameters, latency, memory |
| Output | One comparison table and one analysis report |
