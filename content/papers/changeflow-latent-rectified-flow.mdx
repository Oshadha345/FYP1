## Core Reading Note

ChangeFlow treats a change mask as a coherent generated object rather than only a collection of independent pixel decisions. Multiple sampled masks can be aggregated, and agreement between samples can indicate ambiguity.

## FYP Relevance

| Point | Why it matters |
| --- | --- |
| Region-level mask view | Useful because change masks often represent object or region conventions. |
| Sampling agreement | Offers a possible way to report uncertainty in ambiguous regions. |
| Benchmark caution | Generative models must be compared carefully against strong discriminative baselines. |
