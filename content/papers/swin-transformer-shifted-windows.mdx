## Reading Note

Swin Transformer is relevant to the FYP because it gives a hierarchical Transformer backbone with local window attention and shifted windows for cross-window information exchange.

## FYP Relevance

| Point | Why it matters |
| --- | --- |
| Hierarchical representation | Useful for dense prediction tasks where both local and global context matter. |
| Shifted windows | Reduces attention cost while allowing communication across nearby windows. |
| Baseline family | Provides a Transformer reference family against CNN and SSM/VSS backbones. |
