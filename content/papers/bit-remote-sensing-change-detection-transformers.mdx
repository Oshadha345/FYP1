## Reading Note

BIT-CD represents a bitemporal image using compact semantic tokens and applies a Transformer to model spatial-temporal context.

## FYP Relevance

| Point | Why it matters |
| --- | --- |
| Benchmark baseline | BIT-CD is included in the Week 12 DSIFN-CD and WHU-CD comparison tables. |
| Token view | It helps explain why compact token representations can be useful for high-resolution change detection. |
| Transformer family | It is a non-SSM reference when comparing model families. |
