## Reading Note

This paper is relevant because efficient models can lose the small visual cues that matter in change detection. The key lesson is that compression should not be judged only by overall accuracy; it should also be checked against small-change and boundary-sensitive behavior.

## FYP-Level Use

| Point | Public note |
| --- | --- |
| Mixed precision | Different layers may need different bit widths. |
| Subtle changes | Small changed regions can be damaged by aggressive compression. |
| Evaluation | Efficiency should be measured together with IoU, F1, and boundary metrics. |
