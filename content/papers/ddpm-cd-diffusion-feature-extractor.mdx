## Core Reading Note

The useful idea is not image synthesis itself. The paper uses a diffusion model pretrained on remote sensing imagery as a feature extractor, then trains a lightweight change classifier on top of those features.

## FYP Relevance

| Point | Why it matters |
| --- | --- |
| Unlabeled imagery | Important because labeled disaster change masks are expensive. |
| Feature reuse | Suggests that representation quality can matter as much as decoder design. |
| Benchmark role | Useful comparison point for pretrained feature extraction. |
